XingyiStarry MP 安装说明

1. 当前压缩包是发布外层，许可证与声明位于本层。
2. 打开同目录中的 XingyiStarry-MP-*.zip 安装包。
3. 确保游戏已经完全退出，把安装包内全部文件解压到 AnnW.exe 所在目录，保留目录结构并允许覆盖。
4. 主机与所有客机必须使用相同的插件版本和游戏版本。
5. 启动游戏后，从“遭遇战”的联机入口创建或加入房间。

标准包不包含 BepInEx，需要先安装兼容的 BepInEx 5。
文件名带 with-BepInEx 的整合包包含官方 BepInEx 5.4.23.5 Windows x64 运行时。

正式包不包含游戏文件、其他联机插件、DebugTools、EarlyPatcher 或免 Steam 修改。
双击 Uninstall-XingyiStarry-MP.bat 可卸载。默认只删除本插件，也可选择同时删除整个 BepInEx 框架。
项目及第三方组件的许可证和分发声明位于当前发布外层的根目录和 licenses 文件夹。
