XingyiStarry MP Debug Tools

用途：联机开发和测试，不属于正式版。

安装：
1. 先安装版本匹配的 XingyiStarry MP 主插件。
2. 将本压缩包直接解压到 AnnW.exe 所在目录。
3. 进入联机战斗并由主机按 F8 打开/关闭调试面板。

功能：
- 自定义每次增加量。
- 为指定玩家增加金属、电力或两项资源。
- 为指定玩家充满主动技能。
- 一键为所有玩家增加资源或充满技能。

限制：
- 客机和普通单机不会响应 F8。
- 只有主机能够发起操作；资源和技能修改作为权威调试指令广播给所有客机，并写入权威日志。
- 客机不能提交调试指令，调试包也不增加独立监听端口。
